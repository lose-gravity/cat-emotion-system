# 特征规格 v2 —— 固定窗口版（HLS 实现依据）

> 基准实现: [features_numpy.py](features_numpy.py)（纯 numpy，板端 PS 可跑，与 librosa 1.0.0 对拍误差 <1e-3）
> 所有固定矩阵/系数在 04-改进算法/ 下，由 [00_生成矩阵.py](00_生成矩阵.py) 生成
> 验收标准: 特征分量最大误差 <1e-3（float对拍）; 最终概率差 <0.01

## 1. 输入约定

| 项 | 值 |
|---|---|
| 采样率 | 16000 Hz，单声道（INMP441 配 16k 时钟，24bit 数据取高 16 位） |
| 输入长度 | **固定 24000 采样点（1.5s）** |
| 离线数据（长于1.5s） | 取 0.1s 块能量和最大的连续 1.5s（块=1600点，滑窗15块） |
| 不足 1.5s | 尾部补零 |
| 板上采集 | 建议连续采集 1.5s 块（或滑动 0.5s 步进），配静音门限：块 RMS < 0.005 判为静音、不推理 |

## 2. MFCC 链路（40 维）

帧参数: **n_fft=2048, win=400(25ms), hop=160(10ms), 帧数恒为 151**

1. 两侧各补 1024 个零（center=True, constant）→ 长 26048
2. 分帧 2048 点、帧移 160 → 151 帧
3. 加窗: **周期性 Hann 400 点**（`0.5-0.5cos(2πn/400)`）居中嵌入 2048 点（hann_400.csv；位置 824~1223）
4. 每帧 2048 点 rFFT → 1025 个复数
5. 功率谱: |FFT|² → (151×1025)
6. Mel 滤波: × mel_128x1025.csv（Slaney 归一，128 个三角滤波器，每行非零 5~48 个，**可只存非零项**）→ (151×128)
7. 对数: `db = 10·log10(max(S, 1e-10))`，再整体下限 `max(db, db.max()-80)`（ref=1, top_db=80）
8. DCT-II（ortho）: × dct_40x128.csv → 40 维 MFCC（151×40）

## 3. 其余短时特征（帧移都是 512，与 MFCC 不同！）

| 特征 | 分帧 | 窗 | 细节 |
|---|---|---|---|
| 谱质心（5维统计） | 2048点/帧移512 → **47帧** | 周期性Hann 2048（hann_2048.csv） | 幅度谱\|FFT\|；质心=Σf·S/ΣS；**全零帧质心定义为 0**（librosa 原生会 nan） |
| RMS（5维统计） | 2048点/帧移512 → 47帧 | 无窗 | 两侧补零 1024（constant）；sqrt(mean(x²)) |
| 过零率（5维统计） | 2048点/帧移512 → 47帧 | 无窗 | 两侧补 **edge 填充**（复制边缘值，不是补零！）；先做 `|x|<=1e-10 → 0` 再数符号翻转，除 2048 |

## 4. Delta / Delta-Delta（一阶二阶差分）

librosa 1.0 的 delta = **Savitzky-Golay 滤波**（window=9, polyorder=deriv=order, 边缘 mode='interp'）

- 帧数恒 151 → 直接查表: savgol_d1.csv / savgol_d2.csv（151×151 线性算子）
- 内部为 9 抽头卷积: d1 = [-1/15,-1/20,-1/30,-1/60,0,1/60,1/30,1/20,1/15]（近似值，用 CSV 精确值）
- 边缘 4 帧系数每位置不同，直接存表（见 CSV 前4/后4行）

## 5. 特征组装（295 维，顺序固定）

| 区间 | 内容 | 维度 |
|---|---|---|
| 0~199 | 40 维 MFCC，每维的 [p10, p50, p90, mean, std] | 40×5 |
| 200~239 | delta 一阶，每维均值 | 40 |
| 240~279 | delta 二阶，每维均值 | 40 |
| 280~284 | 谱质心 [p10,p50,p90,mean,std] | 5 |
| 285~289 | RMS 同上 | 5 |
| 290~294 | 过零率同上 | 5 |

百分位数定义: numpy `method='linear'` — 排序后 `(n-1)*p/100` 位置线性插值（n=151 或 47）

## 6. 标准化 + MLP 集成推理（weights_float_final/）

**最终模型 = 2 个 MLP(512,256) 概率平均**（CV 71.4%，详见 [final_meta.json](final_meta.json)）：

```
模型1(model1/): 295维特征     x1 = (f295 - mean1)/scale1
模型2(model2/): 885维分段特征 x2 = (f885 - mean2)/scale2   # 885 = 3段0.5s切片各295维
prob = (softmax(MLP1(x1)) + softmax(MLP2(x2))) / 2
```

单模型前向（两模型结构相同，仅输入维度 295/885 不同）：
```
h1 = relu(x @ W1.T + b1)   # W1: 512xN CSV行主序
h2 = relu(h1 @ W2.T + b2)  # W2: 256x512
logits = h2 @ W3.T + b3    # W3: 3x256
```
- 可选优化: scaler 折叠进第一层（`W1'=W1/scale, b1'=b1-W1·mean/scale`），HLS 少一步，数学等价
- 参数量: 每模型 28.4 万（模型2 第一层 885×512 更大，约 45 万），int8 版两模型共约 700KB——BRAM 放不下全量时权重从 DDR 流式读，片上只留激活缓冲
- 分段特征: 0.5s 切片帧数 51，savgol 用 51 帧版矩阵（savgol_d1_51.csv）；rms/zcr/质心帧数 16

## 7. 量化方案（weights_int8_final/，per-tensor 对称，实测损失 0.23pp）

- 权重: `Wq = clip(round(W/w_scale), -127, 127)`，`w_scale = max|W|/127`
- 激活: `xq = clip(round(x/x_scale), -127, 127)`，`x_scale = max|激活|/127`（各目录 layer_scales.json）
- 推理: int8×int8 → int32 累加；bias 在 int32 累加域加 `b/(x_scale·w_scale)` 定点值
- 实测（5折OOF）: int8 全量化 -0.23pp；int16 全量化 0.00pp（DSP48 18×25 原生精度，推荐）；int8 仅权重 0.00pp

## 8. 触发逻辑

- 饥饿: 单独看饥饿概率 ≥ 0.5（**不是 argmax**），连续 2 段确认 → 舵机出粮
- 焦虑: 焦虑概率 ≥ 0.6 → 逗猫棒+安抚音频
- 亲昵: 不动作；静音门限: 块 RMS < 0.005 不推理
- 完整权衡表见 [final_meta.json](final_meta.json)（OOF 实测）

## 9. 对拍流程

1. `golden/` 下 40 段: `*_pcm.csv`（24000 个 int16，特征提取精确输入）→ `*_features295.csv` / `*_features885.csv`（参考特征）→ `*_probs.csv`（集成概率）
2. HLS C 仿真逐段喂 PCM，对比特征（<1e-3）和概率（<0.01）
3. 全过 → 上板；不一致时先对中间量（FFT 后 151×1025、mel 后 151×128、DCT 后 151×40）

## 10. 性能预算（100MHz）

151帧×(2048点FFT + mel 约14万MAC) + DCT 151×40×128 + 2×MLP 共约 73 万 MAC ≈ **总 <80ms**，实时要求 1.5s 出一次判断，余量近 20 倍。FFT 用 Xilinx FFT IP 或 hls::fft，1 个单元时分复用就够。
